SP

Jesse Vincent (obra) · obra/superpowers

Le framework tient le processus : brainstorming → using-git-worktrees → writing-plans → subagent-driven-development → test-driven-development → requesting-code-review → finishing-a-development-branch.

La version 5.0.0 (9 mars 2026) imposait le développement par sous-agents ; depuis la 5.0.5 (17 mars 2026), c'est une option recommandée, et la version 7 laisse le choix entre sous-agents et exécution dans la session. Les specs et les plans vivent dans docs/superpowers/, et les instructions de l'utilisateur et AGENTS.md priment sur Superpowers.

SD

Spec-driven development · GitHub Spec Kit

Spec Kit enchaîne specify → plan → tasks → implement dans le cadre d'une « constitution » du projet, avec des commandes de contrôle (clarify, checklist, analyze). Chaque étape laisse un document que la suivante reprend.

CE

Compound engineering · Every (Kieran Klaassen)

Une boucle plan → work → review → compound, dont la dernière étape range ce que la review a appris dans docs/solutions ; l'agent retrouve ce dossier depuis AGENTS.md ou CLAUDE.md, et le travail suivant en profite.
