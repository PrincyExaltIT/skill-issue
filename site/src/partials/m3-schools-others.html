SP

Jesse Vincent (obra) · obra/superpowers

Le framework tient le processus : brainstorming → using-git-worktrees → writing-plans → subagent-driven-development → test-driven-development → requesting-code-review → finishing-a-development-branch.

Depuis la version 5 (mars 2026), le développement par sous-agents est le mode par défaut, specs et plans vivent dans docs/superpowers/, et les instructions de l'utilisateur et AGENTS.md priment sur Superpowers.

SD

Spec-driven development · GitHub Spec Kit

Spec Kit enchaîne specify → plan → tasks → implement dans le cadre d'une « constitution » du projet, avec des commandes de contrôle (clarify, checklist, analyze). Chaque étape laisse un document que la suivante reprend.

CE

Compound engineering · Every (Kieran Klaassen)

Une boucle plan → work → review → compound, dont la dernière étape range ce que la review a appris dans docs/solutions et CLAUDE.md, pour que le travail suivant soit plus facile.
