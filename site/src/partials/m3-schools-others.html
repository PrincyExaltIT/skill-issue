SP

Jesse Vincent (obra) · obra/superpowers

Le framework tient le processus : brainstorming → using-git-worktrees → writing-plans → subagent-driven-development → test-driven-development → requesting-code-review → finishing-a-development-branch.

Un implémenteur neuf par tâche, et un reviewer qui rend deux verdicts : conformité à la spec, puis qualité du code. Depuis la version 5 (mars 2026), les instructions de l'utilisateur, CLAUDE.md et AGENTS.md priment sur Superpowers.

SD

Spec-driven development · GitHub Spec Kit

La chaîne specify → plan → tasks → implement, avec une « constitution » du projet. Chaque étape produit un fichier versionné que la suivante lit ; tasks.md marque les tâches parallélisables.

CE

Compound engineering · Every (Kieran Klaassen)

Boucle plan → work → review → compound : la dernière étape range ce que la review a appris dans docs/solutions et CLAUDE.md, pour que le travail suivant soit plus facile.
