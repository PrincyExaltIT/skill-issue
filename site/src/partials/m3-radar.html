D'où vient ce radar

Chaque ligne vient des notes de recherche du 8 octobre 2026 (docs/research/workflows-2026-10.md). Les chiffres d'éditeurs n'ont pas été vérifiés de façon indépendante. Côté autonomie, l'auto mode de Claude Code fait valider chaque appel d'outil par un classifieur, et c'est le mode de départ des sessions dans le terminal et VS Code sur tous les forfaits : depuis la version 2.1.283 d'après la documentation des modes de permission (avant, seulement sur Pro, Max et Team), 2.1.284 d'après le changelog. Cette autonomie a des limites, alors lis-les avant de lui déléguer quoi que ce soit.
