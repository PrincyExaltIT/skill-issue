kit/

La boîte à outils

Tout ce que la formation construit, dans un seul dépôt, sans dépendance externe : quatre skills, un installeur multi-harness, deux pipelines CI, un hook, des gabarits et des evals. Tu peux l'adopter tel quel ou le forker pour ton équipe.

Ce qu'il y a dedans

skill-issue/ ├─ skills/ # les 4 skills, au standard agentskills.io │ ├─ angular-review/ # SKILL.md · scripts/ (scope, scan, findings) · 10 références · assets/ │ ├─ review-fix/ # corrige les findings un par un · scripts/fixes.mjs │ ├─ pr-handoff/ # description de PR/MR + note de passation · scripts/gather.mjs │ └─ skill-smith/ # fabrique et valide des skills · new-skill.mjs, validate.mjs ├─ kit/ │ ├─ install.mjs # installe dans .agents/skills, .claude/skills, … (copie ou lien) │ ├─ harnesses.json # où chaque harness cherche ses skills — daté, à jour │ ├─ ci/github/angular-review.yml # scan sans IA : annotations, résumé du job, porte ; review IA optionnelle │ ├─ ci/github/angular-review-codex.yml # la même review par Codex (job lecture seule + job commentaire) │ ├─ ci/gitlab/angular-review.gitlab-ci.yml # Code Quality dans la MR, note IA optionnelle │ ├─ hooks/ # Claude Code : scan après chaque édition de l'agent │ ├─ gitlab-mirror.sh # miroir GitLab des dépôts (après glab auth login) │ └─ templates/ # AGENTS.md et CLAUDE.md pour un projet Angular ├─ evals/angular-review/ # snapshots, catalogue, déclenchement (run-triggers.mjs), corrigé, score.mjs ├─ docs/sample-review/ # reviews réelles Claude Code et Codex, avec leurs scores ├─ site/ # cette formation (un seul fichier HTML généré) └─ studio/ # les vidéos : scènes HTML rendues image par image

Démarrer en trois commandes

$ git clone https://github.com/PrincyExaltIT/skill-issue.git
$ node skill-issue/kit/install.mjs --target ./mon-app-angular
$ cp skill-issue/kit/ci/github/angular-review.yml ./mon-app-angular/.github/workflows/
Tester le kit
$ npm test

Valide les 4 skills au standard et rejoue les snapshots du scan. Tourne aussi en CI sur le dépôt du kit.

Reconstruire la formation
$ npm run build:site

Régénère ce site depuis les fichiers du kit : catalogue de règles, arborescence, matrice des harnesses.

Re-rendre les vidéos
$ npm run render:videos

Python + Playwright + ffmpeg. Une scène est une page HTML ; modifier un texte, c'est modifier le HTML.

Sur GitLab

Le kit est neutre vis-à-vis de la forge : même installeur, même scan, un job prêt à inclure. Pour recopier les deux dépôts sur GitLab : glab auth login, puis bash kit/gitlab-mirror.sh <groupe> depuis chacun.

# .gitlab-ci.yml de ton projet
include:
  - local: kit/ci/gitlab/angular-review.gitlab-ci.yml   # ou copie le fichier
# Variables CI/CD (masquées) pour la review IA : ANTHROPIC_API_KEY, GITLAB_REVIEW_TOKEN (scope api)
