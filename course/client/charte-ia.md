Un point de départ, à adapter avec la DSI, la RSSI et le DPO. S'il existe déjà une politique d'usage de l'IA dans l'entreprise, elle prime : cette charte ne fait que la décliner pour l'équipe.

## Les outils

- Outils autorisés : [liste validée par la DSI], uniquement avec les comptes fournis par l'entreprise.
- Tout autre outil (chatbot grand public, extension, serveur MCP, skill trouvé en ligne) passe d'abord par [personne ou processus].

## Les données

- On n'envoie jamais à un modèle : données personnelles réelles, secrets, données classées [niveau], code d'un autre client.
- Les données de test sont synthétiques.
- En cas de doute : on demande à [DPO / RSSI] avant.

## Le code produit ou relu par l'IA

- Un humain relit et assume chaque changement, comme pour le code d'un collègue.
- Une suggestion de l'IA n'est jamais une raison de contourner les règles de revue, de test ou de sécurité de l'équipe.
- Les skills et les instructions de l'équipe vivent dans le dépôt et changent par MR.

## Se former

- Chaque membre de l'équipe suit [formation] avant d'utiliser les outils.
- On partage ce qui marche et ce qui rate lors de [rituel d'équipe].

## Signaler

- Une fuite possible, une réponse dangereuse, un comportement inattendu de l'agent : on prévient [contact] le jour même.
